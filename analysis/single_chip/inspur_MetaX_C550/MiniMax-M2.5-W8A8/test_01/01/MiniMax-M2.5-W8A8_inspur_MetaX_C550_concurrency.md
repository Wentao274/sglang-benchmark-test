## 测试场景
使用sglang bench serve基准测试工具对不同并发数，请求上下文长度下的性能变化趋势。

**主要采集指标**：

| 指标                  | 单位         | 含义                                 |
|---------------------|------------|------------------------------------|
| Request throughput  | req/s      | 请求吞吐量                              |
| Input token throughput | tok/s   | 输入token吞吐量                        |
| Output token throughput | tok/s  | 输出token吞吐量                        |
| Total token throughput | tok/s   | 总token吞吐量                         |
| TTFT                | ms         | Time To First Token，首 token 延迟     |
| TPOT                | ms/token   | Time Per Output Token，每 token 生成时间 |
| ITL                 | ms         | Inter-Token Latency，token间延迟       |
| E2E Latency         | ms         | End-to-End Latency，端到端延迟         |

## 📝 分析总结

### 1. 吞吐量性能分析

**请求吞吐量 (QPS)**: 随着并发级别增加，QPS持续上升。
低并发(1,2,4)平均 QPS: 0.44 req/s；
中并发(8,10,16,32)平均 QPS: 1.02 req/s；
高并发(64,80,128)平均 QPS: 1.41 req/s；
最高 QPS 出现在 80 并发，达到 1.41 req/s。

**Token总吞吐量**: 最高达到 14765 tok/s (80 并发)。

### 2. 端到端延迟 (E2E Latency) 分析

E2E延迟随并发增加显著上升。
低并发平均 P99 E2E: 5538ms；
高并发平均 P99 E2E: 76345ms；
最高 P99 E2E 出现在 128 并发，达到 91579ms。

### 3. 首Token延迟 (TTFT) 分析

TTFT随并发增加显著上升。
低并发平均 P99 TTFT: 1277ms；
高并发平均 P99 TTFT: 54007ms；
最高 P99 TTFT 出现在 128 并发，达到 76792ms。

### 4. Token生成时间 (TPOT) 分析

TPOT随并发增加也呈上升趋势。
低并发平均 P99 TPOT: 16.77ms；
高并发平均 P99 TPOT: 174.35ms；
最高 P99 TPOT 出现在 64 并发，达到 174.61ms。

### 5. Token间延迟 (ITL) 分析

ITL随并发增加呈上升趋势。
低并发平均 P99 ITL: 18.74ms；
高并发平均 P99 ITL: 57.38ms；
最高 P99 ITL 出现在 128 并发，达到 57.60ms。

### 6. 综合评估

**吞吐量增长**: 从最低并发到最高并发，QPS增长了 422.2%。
**E2E延迟恶化**: 高并发相比低并发，E2E P99增加了 1553.6%。
**TTFT延迟恶化**: 高并发相比低并发，TTFT P99增加了 5911.7%。
**TPOT延迟恶化**: 高并发相比低并发，TPOT P99增加了 941.0%。

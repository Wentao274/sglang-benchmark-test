- **Kimi-K2.5_int4_2** 相比 **MiniMax-M2.5-W8A8** 总token吞吐量平均变化 **-29.3%**
- **GLM-5-W8A8** 相比 **MiniMax-M2.5-W8A8** TTFT P99平均改善 **99.0%** (延迟降低)
- **Kimi-K2.5_int4_2** 相比 **MiniMax-M2.5-W8A8** TTFT P99平均增加 **41.8%** (延迟增加)
- **GLM-5-W8A8** 无可用数据
